# v2.1.0 (Draft)

## Summary

This candidate updates Sonoff Dongle-M OTBR firmware with the latest Espressif
`esp-thread-br` changes since v2.0.2. It is a Draft PR candidate only and has
not received hardware validation.

- Upstream commits incorporated: 13

## Upstream changes incorporated

- Thread REST APIs are aligned with ot-br-posix 0.6.0, including a v2 REST
  contract and an updated OpenAPI specification and Web UI.
- The Border Router server avoids a REST-initialization deadlock, and the Web
  UI includes upstream display fixes.
- The basic upstream example now enables its Web GUI by default and includes a
  4 MB flash profile. The separate Sonoff 16 MB board profile remains in use.
- The upstream basic-example documentation now recommends ESP-IDF v5.5.6;
  this candidate was built with that version.

## Dongle-M integration

- The only merge conflict was `README.md`. The complete Sonoff-specific README
  was retained because the upstream conflict was its generic SDK/Launchpad
  introduction and does not describe this product.
- No Dongle-M firmware behaviour was intentionally changed: Ethernet-first
  recovery, Wi-Fi fallback/provisioning, IPv6 all-multicast handling, GPIO and
  LED behaviour, dataset handling, and the fixed 115200-baud external MG24
  RCP configuration remain intact.
- Upstream GitHub Actions were excluded. In particular, `pages.yml` was not
  retained; `build_dongle_m.yml` and `check_upstream.yml` match `origin/main`
  exactly.
- The release-image tool continues to use ESP-IDF-generated flash metadata.
  The candidate contains no MG24/RCP firmware.

## Required hardware validation

Before promotion, test this exact image on Sonoff Dongle-M hardware: boot and
LED indications; MG24 Spinel/RCP communication; Thread attach and saved
dataset restore; Web UI plus Thread REST operations; Ethernet operation and
all-multicast traffic; Wi-Fi provisioning/fallback and Ethernet recovery;
and Home Assistant operation. Confirm that no MG24 firmware flashing is
attempted.
