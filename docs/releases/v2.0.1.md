# v2.0.1

## Summary

This release updates the Sonoff Dongle-M OTBR firmware with Espressif’s accumulated upstream changes since the baseline used by v2.0.0. It also documents a manual Thread dataset backup and restoration procedure for upgrades.

New upstream baseline: `29a2345e3f0c61bba9307f3daea5ed0c94388ed3`

Comparison: `0bad9f1f69cebe2e2ab768bbc6f71769a3661e33..29a2345e3f0c61bba9307f3daea5ed0c94388ed3`

## Upstream changes incorporated

The range contains 10 Espressif commits: five feature or maintenance commits and their five merge commits. They:

- update Border Router Wi-Fi MAC handling to use active Wi-Fi interfaces, including hosted Wi-Fi support and clearer handling when Wi-Fi is not initialized;
- simplify RCP-update configuration and update the component dependency to 1.7.0 while retaining the Dongle-M-specific UART and GPIO configuration; and
- refresh upstream hardware guidance, examples, and CI. The upstream CI uses an internal ESP-IDF v6.2 image for some jobs; this is a CI environment choice, not a project minimum. The supported build version for this release is ESP-IDF v5.5.4.

## Dongle-M impact

The merge required simple conflict resolution in shared documentation and configuration files. Dongle-M board support, Ethernet/Wi-Fi policy, LED/RCP handling, release-image tooling, and Igor Sweet’s Ethernet all-multicast fix from PR #4 were retained. That fix enables all-multicast reception on the Ethernet backbone for IPv6 Border Router traffic with ESP-IDF v5.5.4. No MG24/RCP firmware is included in the ESP32 release image.

## Dataset upgrade notes

README now includes a collapsible six-step procedure to back up the Active Operational Dataset before flashing, reconnect Ethernet or configure Wi-Fi, restore the dataset after normal operation resumes, and verify the existing Thread network. Credential preservation is not yet guaranteed during upgrades, so users should keep a secure dataset backup. This manual procedure remains useful after any future automatic-preservation work because flashing errors, full erases, and partition changes can still cause data loss.

## Validation

The candidate was physically validated on Sonoff Dongle-M hardware: boot, MG24 RCP communication, Thread operation, Web UI, Ethernet, Wi-Fi provisioning/fallback, Home Assistant operation, and LED indications all passed. No claim is made that upgrade credentials are automatically preserved.
