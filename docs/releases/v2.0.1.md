# v2.0.1 (draft)

## Summary

This draft updates the Sonoff Dongle-M OTBR firmware with Espressif’s accumulated upstream changes since the baseline used by v2.0.0.

## Upstream range

Previous upstream baseline: `0bad9f1f69cebe2e2ab768bbc6f71769a3661e33`

New upstream baseline: `29a2345e3f0c61bba9307f3daea5ed0c94388ed3`

Comparison: `0bad9f1f69cebe2e2ab768bbc6f71769a3661e33..29a2345e3f0c61bba9307f3daea5ed0c94388ed3`

## Upstream changes incorporated

- Updated Border Router Wi-Fi MAC handling to use active Wi-Fi interfaces, including hosted Wi-Fi support and clearer handling when Wi-Fi is not initialized.
- Simplified the RCP-update configuration and updated the component dependency to 1.7.0 while retaining the Dongle-M-specific UART and GPIO configuration.
- Incorporated upstream hardware-guide, example, and CI maintenance changes. The upstream CI uses an internal ESP-IDF v6.2 image for some jobs; this is a CI environment choice, not a project minimum. The supported build version for this candidate remains ESP-IDF v5.5.4.

## Dongle-M impact

The merge required simple conflict resolution in shared documentation and configuration files. Dongle-M board support, Ethernet/Wi-Fi policy, LED/RCP handling, release-image tooling, and Igor Sweet’s Ethernet all-multicast fix were retained. No MG24/RCP firmware is included in the ESP32 release image.

## Validation

Physical Sonoff Dongle-M hardware validation is **PENDING**. Do not treat this draft as a release. Test boot, MG24 RCP communication, Thread attach/restore, Web UI, Ethernet, Wi-Fi provisioning/fallback, Home Assistant operation, and LED indications before promotion.
