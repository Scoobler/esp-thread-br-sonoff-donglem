Scoobler · OpenThread Border Router

Sonoff Dongle-M firmware flasher

Flash your ESP32 host firmware directly over USB-C. No software to install; use desktop Chrome or Edge.

1 · Choose what to do

Fresh installation erases all ESP32 flash. Back up your Thread Active Dataset and prepare to configure Wi-Fi again. The MG24 RCP is separate and is not flashed.

2 · Select firmware

Loading published release details…

The firmware is served from this GitHub Pages site. Release files are verified against published SHA-256 checksums before flashing.

Custom files are not signature-verified. Only use a trusted merged image at 0x0 for Fresh installation or a Dongle-M upgrade image at 0x20000 for Upgrade. Wrong images or offsets can make the ESP32 unbootable.

3 · Flash over USB-C

Close MobaXterm, serial monitors and Sonoff Dongle Flasher before proceeding. The MG24 must already be running a compatible Sonoff OpenThread RCP.
